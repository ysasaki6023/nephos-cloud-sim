# Nephos — 2 次元 anelastic 雲シミュレーター (WebGL2)

`index.html` を Chrome / Safari / Firefox で開くだけで動く単一ファイルのアプリ。x–z 断面 (横 = 水平距離、縦 = 高度) の第一原理雲モデルを GPU (WebGL2 フラグメントシェーダ) で解く。

## モデル
- anelastic 近似 (∇·(ρ₀v) = 0)、基本場 θ₀, ρ₀, π₀ は静力学積分
- 予報変数: u, w, θ, q_v, q_c (雲水), q_r (雨), q_i (雲氷), q_s (雪)
- 移流: MacCormack 半ラグランジュ + 局所クランプ、乱流: Smagorinsky
- 圧力: 幾何マルチグリッド (重み付き Jacobi、地形まわりは補正緩和 0.7) + 仕上げ Jacobi
- 微物理: 飽和調節、Kessler 型暖かい雨、氷相 (均質/不均質凍結、昇華成長、WBF、雪変換、着氷、融解)
- 境界: 上端剛体蓋 + スポンジ、側面は 開放 (吸収層 + Dirichlet 圧力) / 周期 / 閉鎖 を選択
- 追跡粒子 (空気塊) と成長する雲粒 (拡散成長・捕捉・終端速度、氷晶化)

## 使い方
- 上部のプリセットを選んで再生。左のツール (探査・粒子・雲粒・熱泡・地形・材質) の操作説明は画面上部に出る
- 表示バーで 塗り / 等値線 A / 等値線 B / 風 / 相の色 / 地上天気 を重ねる。「統合表示」で一括
- 「◐ アート」(A キー) で UI を隠して眺めるモード。Esc で戻る
- 「ⓘ」に支配方程式・雲の色の意味・制約の説明

## 開発メモ
- `#autotest<preset>` ハッシュ + `?steps=…&grid=…` で headless 検証用の自動実行 (console に `AUTOTEST {…}` JSON)
- 詳細な設計判断はコードのコメント参照
